# NLP & LLM for Finance and Accounting Research

## Workshop Overview

A two-day workshop at the University of Sheffield introducing students to textual analysis methods with hands-on exercises.

## Workshop Content

This workshop covers foundational concepts and practical applications of Natural Language Processing (NLP) and Large Language Models (LLMs) in the context of finance and accounting research. Participants will learn how to apply these techniques to analyze financial documents and accounting texts.

### Key Topics

- Introduction to NLP and LLM fundamentals
- Dictionary-based sentiment analysis [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/helenlu-vbs/NLP_LLM_for_Finance_and-Accounting_Research-Sheffield-/blob/main/001_use_LM_dictionary.ipynb)
- Textual distance measures
- Transformers and open-source LLMs
- Fine-tuning open-source LLMs
- Using frontier LLMs, RAG in combination with traditional NLP tools
