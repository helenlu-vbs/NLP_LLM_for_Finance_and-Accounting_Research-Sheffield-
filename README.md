# NLP & LLM for Finance and Accounting Research

## Workshop Overview

A two-day workshop at the University of Sheffield introducing students to textual analysis methods with hands-on exercises.

## Workshop Content

This workshop covers foundational concepts and practical applications of Natural Language Processing (NLP) and Large Language Models (LLMs) in the context of finance and accounting research. Participants will engage in hands-on exercises to develop practical skills in text analysis and machine learning techniques.

### Key Topics

- Introduction to NLP and LLM fundamentals
- Dictionary
- Textual distance measures
- Transformers and open-source LLMs
- Fine-tuning open-source LLMs
- Using frontier LLMs, RAG in combination of traditional NLP tools
